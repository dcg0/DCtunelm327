# Política de seguridad

## Versiones soportadas

La rama `main` es la única línea de desarrollo que recibe correcciones de seguridad en este repositorio. Las versiones distribuidas desde otros repositorios o releases deben evaluarse por separado.

## Reportar una vulnerabilidad

No publiques vulnerabilidades, credenciales ni datos de vehículos en issues, discusiones o pull requests públicos. Usa el formulario privado de GitHub para este repositorio:

- [Crear un reporte privado de vulnerabilidad](https://github.com/dcg0/DCtunelm327/security/advisories/new)

Incluye, cuando sea posible, pasos para reproducir, versión o commit afectado, impacto esperado y una propuesta de mitigación. Redacta cualquier secreto, identificador del vehículo o información personal antes de adjuntar logs.

Si el formulario no está disponible para tu cuenta, contacta a los mantenedores mediante un canal privado indicado en el perfil u organización del repositorio; no publiques los detalles técnicos.

## Coordinación

Los reportes se revisarán de forma privada. La divulgación pública debe coordinarse con los mantenedores y realizarse después de que exista una corrección o una mitigación razonable.
